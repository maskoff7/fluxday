# Brand

## Naming exercise

Candidates: Fluxday, Flowmark, Dayflow, Runlet, Floatline, Flowmint, Cashloom, Fundpath, Daymark, Morrow, MorrowFlow, Tiderun, Balanceo, Balora, Saldo, Cashline, Flowcast, Foreflow, Runway, Liquida, Tidebook and Futureline.

The first screen favoured names that suggest movement through calendar time without sounding like bookkeeping. Obvious web/App Store conflicts were found for Flowday, Floatline, Flowmint, Cashloom, Fundpath, Runlet, Daymark, Morrow, Morrowline, Tiderun and Balora. This was only an informal collision check, not professional trademark clearance.

## Chosen name

**Fluxday** combines daily planning with the movement of money. It is short, pronounceable in Russian and English, and directly supports the product's day-by-day mental model. A historical open-source task-management project used the same word, so the name should receive a formal trademark and storefront review before commercial distribution.

Positioning: **See every future balance before it becomes a surprise.**

Possible tagline: **Your money, mapped day by day.**
